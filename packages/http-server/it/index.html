Quickstart
Claude Desktop, Claude Code e Cursor parlano tutti MCP. Scegli quello che usi.
1
Claude Desktop · Apri Impostazioni → Connettori e seleziona Aggiungi connettore personalizzato. Incolla l'URL dell'endpoint e conferma. I connettori remoti richiedono un piano Pro, Max, Team o Enterprise.
installazione UI
2
Claude Code · Aggiungi a .mcp.json nella radice del progetto (oppure ~/.claude.json per un server globale): 
{
  "mcpServers": {
    "normattiva": {
      "url": "https://normattiva-mcp.adellorto.com/api/mcp"
    }
  }
}
3
Cursor · Stesso JSON, in .cursor/mcp.json: 
{
  "mcpServers": {
    "normattiva": {
      "url": "https://normattiva-mcp.adellorto.com/api/mcp"
    }
  }
}
ChatGPT espone MCP tramite App e Connettori (in precedenza «Connectors»). I server personalizzati richiedono Pro, Team, Enterprise o Edu e l'attivazione della Developer Mode.
1
Apri Impostazioni → Connettori (o App e Connettori) e abilita la Developer Mode.
developer mode
2
Aggiungi un nuovo server MCP che punta a: 
https://normattiva-mcp.adellorto.com/api/mcp
3
Esegui un prompt o richiama il connettore da Deep Research. Nota: senza Developer Mode, Deep Research si aspetta server MCP che espongono i tool search e fetch — questo server usa tool specifici di dominio (search_acts, read_article, read_act, list_articles, recent_updates), quindi Developer Mode è necessaria.
Preferisci eseguire il server come sottoprocesso locale? È anche pubblicato come normattiva-mcp su npm.
1
Sostituisci la configurazione URL con un comando stdio. Funziona in qualsiasi client MCP che accetta command/args: 
{
  "mcpServers": {
    "normattiva": {
      "command": "npx",
      "args": ["-y", "normattiva-mcp"]
    }
  }
}
2
Richiede Node.js ≥ 20. Nessuna dipendenza nativa; l'API OpenData di Normattiva è aperta e non richiede chiavi.
