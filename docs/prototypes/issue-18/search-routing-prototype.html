The deep seam

          

            
Model: preserve the request's facts and contradictions in find_acts({request}).

            
Planner: parse, normalize aliases, validate, and select exact, relevance, advanced, reject, or clarify.

            
Adapter: translate a closed plan to Normattiva and validate its response—not merely the HTTP status.

            
Result: return identified act, candidates, or no candidates with route and degradation metadata.

One narrow fallback

          
Only when the observational relevance capability is classified as unavailable may discovery retry with documented chronological order.

          
degraded: true The response must say that relevance ranking was lost.

        

      

    


    

      

        

          
Accepted decision

          
Use the shallow public router

          
find_acts({ request: string })
continue_acts({ cursor: string })

          
Keep exact/discovery/advanced distinctions inside a deterministic planner. This is the only tested design that simultaneously reduced schema weight and improved every model family.

          
          
          
          
This prototype records a choice locally in the browser only; report the verdict in the issue/conversation.
